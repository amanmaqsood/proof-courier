# Workspace Notes

## Product

- Proof Courier is a synthetic WebMCP demonstration of minimum, purpose-bound eligibility disclosure.
- The current surfaces are a private wallet, fellowship verifier, and judge-facing Evidence Room.
- The desired product position is negotiated, human-authorized disclosure for the agentic web.
- Raw source values must remain inside the wallet.
- Final application submission must remain a visible human action.

## Tools and channels

- Source and public competitor research: authenticated GitHub CLI and Agent Reach.
- Hosting: Vercel.
- Native agent verification: ChatGPT in-app browser and WebMCP-enabled Chrome.
- Protocol smoke tests: GoogleChromeLabs WebMCP evals.
- Submission: Devpost and public YouTube video.

## Working language

- Request Firewall: deterministic policy evaluation that blocks overreach before a consent request or export capability exists.
- Counterproposal: a smaller set of derived predicates offered instead of requested raw fields.
- Consent grant: the human-approved recipient, purpose, claim set, lifetime, and one-use limit.
- Capability lifecycle: absent, prepared, human-approved, available once, spent, receipt-only.
- Public-field leading: the state defined in `workflows/competitive-leadership-loop.md`, never a promise about private entries or judge results.

## Accepted decisions

- Use the official criteria as the primary competitive score.
- Preserve the right to pivot the fellowship wrapper only under the workflow's evidence gate.
- Keep competitor rankings private.
- Prioritize secure product gates before the reusable package and conformance CLI.
- Use existing/free infrastructure by default; spending above INR 8,000 requires approval.
